# 调研要求表单需求

## 一、目标与范围

让用户填写研究市场、产品品类、完整检索要求和可选的价位段策略，并将结构化要求交给 AI 执行。此页面独立于结果网站。

| 区域 | 需求 |
| --- | --- |
| Amazon 站点 | 按区域展示 23 个独立商城；支持单选、多选、全选、全取消、反选 |
| 产品品类 | 自由输入，必填 |
| 检索要求 | 一个文本区承载产品条件、关键词、排除条件及其他要求 |
| 价位段策略 | 可选；选择币种，自定义添加/删除行，每行只填写起始价格、终止价格，无名称字段 |
| 保存草稿 | 在当前浏览器保存并恢复 |
| 确认保存 | 检查至少一个站点和产品品类，保存后打开交接弹窗 |
| 交接弹窗 | 提醒告知 AI 已完成输入，支持一键复制和下载 JSON |
| 失败状态 | 目录加载错误、存储不可用或复制失败时提供明确反馈与手动复制入口 |

页面已移除产品资料策略、报告模板、单独检索词输入和被用户删除的页脚说明。

## 二、数据约定

- 当前导出包含 `schemaVersion`、`scope.marketplaces`、`scope.productCategory`、`scope.researchRequirements`、`priceBandStrategy` 和 `savedAt`。
- 继续兼容已有 `market-research-intake.v1` 浏览器草稿；旧字段中的显式要求迁入可见文本区，不重新增加隐藏的资料策略或模板选择。
- 表单发布包仅含空白页面与公开站点目录，不包含用户填写内容。
- 用户复制或下载并交给 AI 后，才进入后续研究工作。

### 价位段数据

```json
{
  "priceBandStrategy": {
    "currency": "USD",
    "boundary": "lower-inclusive-upper-exclusive",
    "tiers": [{"startPrice": 0, "endPrice": 60}]
  }
}
```

- 每段两个端点均为非负有限数，终止价格必须大于起始价格；按起始价格升序保存。
- 区间含起始、不含终止；允许相邻和间隔，不允许重叠。最后一段也需明确终止价格。
- 未设置策略时保留空币种和空数组；添加价位段后必须选择币种。没有覆盖的价格不会从调研范围排除。
- 草稿保留输入字符串与编辑顺序；旧版名称不再使用，已有起始价格保留，终止价格缺失时提示补填。
- 复制给 AI 的文本包含区间摘要与完整 JSON；下载使用同一个确认快照。

## 四、验收条件

- 站点全选、全取消、反选及逐项选择正确更新选择数量。
- 至少选择一个站点并填写品类后，才能确认保存。
- 确认弹窗提供一键复制、JSON 下载和完整文本手动选择。
- 保存及复制内容不再包含独立检索词、资料策略或模板字段。
- 旧草稿迁移后的要求对用户可见且可编辑。
- 发布子路径可加载站点目录，浏览器存储与复制失败有反馈。
- 调研结果网站不包含此表单页。
