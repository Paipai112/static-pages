# 表单设计依据

## 一、当前归档

[打开当前 HTML 设计与实现归档](index.html)。此页与站点源码 `index.html` 完全一致，旁边的 `amazon-marketplaces.js` 是相同站点目录。HTML 同时作为可编辑设计实现依据与浏览器预览。

本归档仅包含用户最新确认的站点选择、产品品类和检索要求，以及保存、复制和下载交接流程。早期包含“产品资料”“报告模板”和独立“检索词”的 PDF 未收入本交付，以免与当前需求混淆。

## 二、编辑方式

先修改站点根目录的两个源码文件。需求确认后同步更新本目录归档，使预览继续对应实际交付。功能行为的验收结论单独记录在 `../acceptance.md`。
