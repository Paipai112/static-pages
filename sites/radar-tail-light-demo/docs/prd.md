# 雷达尾灯市场研究 Demo 需求

## 一、目标与范围

提供可供用户体验的市场报告网站，分为 Roadmap 和竞品分析两个菜单页。此交付演示交互与报告组织方式，研究输入表单单独发布。

| 页面 | 用户操作 | 结果 |
| --- | --- | --- |
| Roadmap | 选择品牌、价格、关注产品 | 更新品牌 × 价格地图 |
| Roadmap | 缩放、展开至整页、收起或按 Esc | 浏览产品地图并恢复原界面 |
| 竞品分析 | 切换产品、厂商、大盘 | 呈现对应聚合层级的趋势 |
| 竞品分析 | 切换销量或销额、调整期间 | 更新纵轴和期间数据 |
| 竞品分析 | 搜索、输入销量及销额范围 | 更新候选项集合 |
| 竞品分析 | 勾选、取消、全选、全取消、反选 | 更新曲线；候选项不因勾选状态重新排序 |
| 图表 | 悬浮或聚焦数据点、触屏轻触 | 查看该点摘要、数值与来源 |
| 视图配置 | 命名导出、导入已有配置 | 复用两页显示状态 |

筛选栏位于图表上方。产品、厂商各自记忆选择集合；大盘汇总完整研究池，不随候选勾选改变。

## 二、数据与状态

- Roadmap 采用已有商品快照；卡片组织、元素及品牌系列泳道遵循原实现。
- 分析数据为设计示例，不能解释为真实市场变化。
- 空选择、无匹配候选、无可用数据和不合法范围均需给出对应状态。
- 全选、全取消和反选仅作用于当前筛选结果。
- 单次勾选与取消不改变候选排序；显式改变排序条件可以改变顺序。
- 地图展开时其他页面内容隐藏并不可交互；关闭后恢复页面位置和焦点。
