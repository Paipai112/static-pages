# 报告网站设计档案

## 一、设计文件

- [可编辑 Pencil 设计](report-website.pen)。
- [六页设计 PDF](exports/report-website-design.pdf)。
- [桌面设计预览](index.html)，支持菜单及产品、厂商、大盘画板切换。
- `exports/` 包含 Roadmap、产品、厂商、大盘、移动端、配置与空态画板，以及产品卡片细节。
- `assets/products/` 包含 Pencil 源文件引用的 7 张商品图片。

这些设计来自已批准的 2026-10-13 结果网站设计稿。画板中的市场数字是示例；静态控件不代表交互已经通过验收。

## 二、当前实现依据

当前交付依据为本目录所属工程的 `demo.html` 及源码。用户在设计批准后进一步要求：

- 地图可展开至整个网页，并隐藏其他界面。
- 分析筛选栏移到图表顶部横向展示。
- 候选项的勾选和取消保持原位置。

这些改动已进入当前源码；旧 Pencil 画板仍保留原评审版本，不重绘为不存在的设计确认记录。完整指令摘录见 `../prd.md`。

本设计档案不包含调研输入表单，表单在另一站点独立交付。
