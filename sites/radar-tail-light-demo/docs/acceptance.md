## 三、Roadmap 留白修订（任务 #6）

需求来自用户对正式页面的截图反馈：“周围的空白太大了，尽量不要留空白。”延续当前聊天中无需额外确认、直接发布查看的授权。固定输入为 c066123e37b71b193f6aa0ebf8aae4202e9e4a94 的现有 Demo。

- Roadmap 使用全宽布局，页边 12–20px，底部 8px。桌面地图填充剩余屏高。
- 价格轴、网格与卡片纵向位置按可用高度一同延展，卡片尺寸、横向组织和价格规则沿用原实现。适配按 100% 基准计算，手动缩放不触发布局重排。
- 仅 Demo 启用 `fillViewport`，原 Roadmap 调用默认关闭。分析页继续使用既有阅读布局。
- `npm run build:pages` 成功，Vite 8.0.13，54 模块；复用同版本本地依赖，未新装依赖。
- 实际生产包通过本地静态子路径预览。在 2515×1213 下，main 全宽，地图 x=21px、宽 2473px、高约953px，页脚距底8px，文档尺寸与视口一致；地图内部底色延展至底部。
- 在 390×844 下查看实际页面，文档宽390px、地图高约549px，控件换行，地图在自身区域滚动。
- 未新增或执行单元/自动化测试，未执行完整交互验收。
